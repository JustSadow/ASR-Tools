# ASR Tools 動作工作流程

> 適用：Maya 2025 + AdvancedSkeleton 6.940
> 工具：`AS × Mixamo 工具`（工具架按鈕）
> 最後更新：2026-11-09

---

## 一、整體流程

```
模型完成 → AS 綁骨 → 取得 Mixamo 動作 → 工具批量套到 rig → 動畫師手修 → (錄 GIF 給主管看)
```

| 步驟 | 誰做 | 說明 |
|---|---|---|
| 1. 綁骨 | 人 | 用 AS 綁好骨架、刷好權重，存成 `角色_Rig.mb`（例如 `角色A_Rig.mb`） |
| 2. 取得動作 | 人 | 到 Mixamo 挑動作下載（兩種方式，見第三節） |
| 3. 套動作 | **工具** | 一次丟多個 FBX，自動 bake 到 AS 控制器，另存 `角色_動作.mb` |
| 4. 手修 | 動畫師 | 打開 `角色_動作.mb` 修細節 |

---

## 二、安裝與更新

1. 從 GitHub 的 Releases 下載最新的 `ASR_Tools_vX.Y.Z.zip`，解壓縮
2. 開 Maya 2025，把 `install.py` 拖到 viewport → 工具架多出 **ASR Tools**、**WeightTransfer**、**BuildPose**
3. 之後的更新：工具視窗右上角「版本／更新」（有新版時會變綠色），或在工具架 **ASR Tools 按鈕上按右鍵 → 版本管理／更新**
   - 可以裝任何一個版本：裝舊版就是退回上一版
   - 每次安裝都會先備份目前的版本（保留最近 5 份）

> 這個工具**不會修改 AdvancedSkeleton 本身的任何檔案**。

---

## 三、取得 Mixamo 動作（兩種方式）

### 方式 A：上傳自己的角色（品質較好）

1. 從 AS 匯出模型＋骨架的 FBX，依 Mixamo 的要求整理（骨頭用 Mixamo 名稱、五根手指、一組 UV、不帶動畫）後上傳
2. 在 Mixamo 挑動作下載；來源選「客製模型」

### 方式 B：直接用 Mixamo 預設角色（Y Bot / X Bot）（快，不用上傳）

- 不用上傳自己的角色，在預設角色上挑動作直接下載
- **一次下載，所有角色都能共用**
- 工具會自動判斷是預設角色，並自動處理：
  - 把 T-pose 對齊成 rig 的 bind pose
  - 依腿長比例縮放移動距離（步幅、跳躍高度）
  - 腳的高度對齊地面，著地時不會穿地或飄起來
- 缺點：動作是照正常人比例做的，Q 版角色頭大手短，**手碰頭、雙手合十、前傾的頭部**比較容易需要手修

### 下載設定（兩種方式都一樣）

| 選項 | 設定 |
|---|---|
| Format | FBX Binary (.fbx) |
| Skin | **Without Skin** |
| Frames per Second | **30** |
| Keyframe Reduction | none |

檔名建議直接取好動作名，例如 `Hurt.fbx`、`Run.fbx`（工具會預設用檔名當動作名稱，也可以在表格裡改）。

## 四、批量 Retarget 分頁

1. **AS 綁好的 rig 檔**：選 `角色_Rig.mb`（不會被修改）
2. **角色名**：自動帶入（`角色A_Rig.mb` → `角色A`），輸出檔名的前綴
3. **輸出資料夾**：選要存的地方
4. 把 Mixamo FBX（或整個資料夾）**拖進表格**
5. 在「動作名稱」欄改成要的名字，例如 `Sword And Shield Impact` → `Hurt`，輸出就是 `角色A_Hurt.mb`
6. 按 **開始批量**（背景處理，Maya 可以繼續用）

### 每個動作工具會做的事

1. 開 rig 檔 → 設定 30fps
2. 開新的 namespace 匯入動作（不會跟 rig 的骨架撞名）
3. 第 -1 格：動作骨架歸零（Mixamo 預設角色會再對齊成 rig 的姿勢）
4. Connect → Bake（只 bake 動作的範圍）→ Disconnect（等同 AS MoCapMatcher）
5. **刪掉匯入的動作骨架**
6. 第 -1 格 key 一個 bind pose（隨時可以跳回原始姿勢）
7. Euler Filter（修正旋轉 ±180° 翻轉）
8. Key Reducer
9. 另存 `角色_動作.mb`

### 選項

| 選項 | 預設 | 說明 |
|---|---|---|
| Key Reducer 精度 | **3%**（Percentage 模式） | 約減少 75～80% 的 key，誤差約 1.5 cm 以內。**不要用 Absolute 模式**，同樣填 3 誤差會到 40 cm 以上 |
| Euler Filter | 開 | 不會改變姿勢，只是讓曲線好修 |
| In Place | 關 | 去掉前後左右位移，角色原地播放（保留上下起伏與擺動，頭尾對齊可循環）。Mixamo 下載時沒勾 In Place 的移動動作用這個 |
| 覆蓋已存在的檔案 | **關** | 關的時候，已存在的檔案（可能動畫師已經修過）會**略過**，表格會用橘字提醒。打開後還會再跳一次確認 |

### FK / IK

- 維持 rig 原本的設定：**腳 IK、手 FK**
- FK、IK 控制器都有 bake，動畫師切換 FK/IK 時兩邊都有動作
- 手臂用 FK 時手的位置會差幾公分（Mixamo 也會轉手臂中間的扭轉骨）；手要精準貼東西時，切成 IK 即可

## 四之二、單一動作：Retarget 分頁

想邊看邊套、一次只做一個動作時用這個（不用背景處理，結果直接出現在 viewport）。

1. 在 Maya **打開乾淨的 rig 檔**（例如 `角色A_Rig.mb`）
2. 開工具 → **Retarget** 分頁，確認「目前場景」顯示綠色 `✔ AS rig`
3. 把動作 FBX 拖進去，「來源」用自動判斷即可（判斷錯時再手動選，見第四之三節）
4. 確認「動作名稱」和「另存資料夾」，下面會顯示另存檔名，例如 `角色A_Run_Forward.mb`
5. 按 **Retarget 到目前場景**，會先問：
   - **套用並另存新檔**（建議）：套完直接存成新檔，乾淨的 rig 檔不會被動到
   - **只套用，先不存**：套完先不存檔，但場景名稱會先改成新檔名，之後按 Ctrl+S 也不會蓋到乾淨的 rig
   - **取消**
- 如果場景的控制器已經有動畫（例如已經套過一次），會先提醒你，建議重新打開乾淨的 rig 再套
- Retarget 和批量 Retarget 各自有自己的 Key Reducer／Euler Filter 設定（滑鼠移到旁邊的 ? 看說明）

## 四之三、來源（支援的動作庫）

「來源」選單決定動作 FBX 的骨頭名稱怎麼對應到 AS。預設**自動判斷**（依骨頭名稱找最符合的），判斷錯時再手動選；選的跟檔案看起來不一樣時 log 會提醒。

| 來源 | 說明 |
|---|---|
| Mixamo 預設角色（Y Bot／X Bot） | 不用上傳自己角色，直接下載 |
| 客製模型 | 自己上傳到 Mixamo 的骨架 |
| 3ds Max Biped（Bip001） | Unity Asset Store 動作包常見；名稱對應內建在工具裡，不用裝 AS |
| Unreal（pelvis／spine_01／upperarm_l） | Unreal 商城與部分 Unity／3ds Max 動作包；名稱對應內建在工具裡，不用裝 AS |
| Rokoko、Character Creator（ActorCore）、MotionBuilder、DeepMotion、Move AI、Plask、HY-Motion、MotionMaker、iPi Soft | 其他動作庫／動捕／AI 動作。名稱對應內建在工具裡 |

> 所有來源的骨頭名稱對應都內建在工具裡，**Retarget 不需要裝 AdvancedSkeleton**。

- 除了「客製模型」以外，其他來源都會自動：對齊成 rig 的 bind pose、依腿長比例縮放移動距離、腳對齊地面
- 動作庫的**授權**請先確認可以商用（例如 CC BY-NC 不能用在公司專案；部分 Unreal 商城素材只能用在 Unreal 專案）

## 四之四、錄影分頁

把目前 viewport 錄成影片，方便給主管或組員看。

| 選項 | 說明 |
|---|---|
| 範圍 | 時間軸，或自訂開始／結束格 |
| FPS | 跟場景一樣，或 60／30／24／15／12／10；會自動換算，播放速度跟 Maya 一樣 |
| 尺寸 | 跟視窗一樣、1920×1080、1280×720、960×540、640×360、自訂 |
| 循環次數 | 整段重複播幾次，短的循環動作才看得清楚；頭尾同一個姿勢時自動去掉最後一格 |
| 格式 | MP4、GIF（建議 15fps 以下、小尺寸）、PNG 序列 |
| 顯示 | 骨頭、控制器、格線、HUD 要不要錄進去；錄完自動恢復原本設定 |

- 錄的是**最後點過的 viewport**，用它的鏡頭和顯示設定
- GIF 會在背景轉檔，Maya 可以繼續用

## 四之五、雙手武器骨架分頁

1. 「雙手武器骨架」分頁：選乾淨的 rig、選「開槍姿勢」FBX（例如 Mixamo 免費的 Firing Rifle，自己下載一次，工具會記住）→「開始調整」→ 在 viewport 調整槍和左手 →「確定，綁到乾淨 rig」→ 另存帶槍 rig
2. 之後批量 Retarget 的 rig 改用 `_Gun.mb`，勾「雙手武器」（跑步類再勾 In Place）
3. 槍預設隱藏（Gun_Ctrl.showGun = 0），非射擊動作照常用同一份 rig

| 控制 | 作用 |
|---|---|
| Gun_Ctrl.gunInHand | 1 = 槍跟右手，0 = 槍留在原地 |
| Gun_Ctrl.showGun | 顯示／隱藏槍 |
| IKArm_L.followGun | 1 = 左手跟著槍晃動（IK 本身照樣能調）；用視窗上方「左手跟槍 開／關」切換不會跳 |
| Gun_Weapon（骨頭） | 掛在右手下、跟著槍，匯出 FBX 會帶槍的動作 |

- 換彈、丟手榴彈這類會放開槍的動作：不要勾「雙手武器」，或之後 key followGun／gunInHand
- 用 AS 重新 Build 骨架會清掉 Gun_Weapon，Build 之後要重新加槍

## 五、常見問題

**Q：Mixamo 上傳後一直失敗／不認得骨架？**
- 用頁籤 1 重新轉一次（會清掉多的 UV 和動畫 Take、補手指）
- 還是不行：重新整理頁面、重新登入、換瀏覽器，或晚點再傳（Mixamo 網站本身不太穩）

**Q：手指只有四根（或更少）可以嗎？**
- 可以。頁籤 1 會暫時補上沒有權重的手指，只是為了讓 Mixamo 認得，不影響模型

**Q：已經手修過的檔案會被蓋掉嗎？**
- 預設不會。除非勾「覆蓋已存在的檔案」並在確認視窗按「是」

**Q：自己在 Maya 匯出要給 Mixamo 的 FBX 要注意什麼？**
- UV 只留一組（UV Editor → UV Sets，只留 `map1`）
- 匯出時 Animation 取消勾選
- 直接用頁籤 1 轉就不用記這些

**Q：跟以前手動用 MoCapMatcher 做的有什麼不同？**
- 步驟一樣，結果更準：AS 內建的 Mixamo 對應表把 `Spine1` 對到 Mixamo 的 `Spine1`，但我們上傳的骨架沒有這個名字，手動做的時候 `FKSpine1_M` 其實沒吃到動作；工具有接上
